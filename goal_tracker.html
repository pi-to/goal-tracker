クラウド同期の設定（管理者・1回だけ）

保存先は Firebase（Google Cloud）の無料枠です。誰でも自分の Google アカウントでログインでき、データはアカウントごとに分かれます。プロジェクトIDや API キーは、この画面に貼るだけで、ソースコードへ直書きしないでください。

  1. Firebase Console でプロジェクトを作る（Blaze 課金は不要・Spark 無料でOK）
  2. Authentication → Sign-in method → Google を有効にする
  3. Authentication → Settings → Authorized domains に を追加
  4. Build → Firestore Database を作成（本番モードでOK）
  5. 歯車 → プロジェクトの設定 → マイアプリ → ウェブアプリを追加し、firebaseConfig をコピー
  6. 下に貼り付けて保存。Firestore の Rules はリポジトリの firestore.rules と同じ内容にする

Firestore ルール（コピーして Rules に貼る）。各ユーザーは自分のデータだけ読めます。

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

保存すると、このサイトを開いた他の人も設定なしで「Googleでログイン」できます。今のページのオリジンは です。
